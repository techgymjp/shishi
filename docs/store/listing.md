## 日本語

**アプリ名**（30 文字以内）

```
鹿威しカコーン 〜日本庭園のタイミングゲーム〜
```

**簡単な説明**（80 文字以内）

```
竹筒が石を打つ「カコーン！」の瞬間にタップ。苔むす日本庭園、茶室、しだれ桜。音と景色に癒やされるワンタップのタイミングゲーム。
```

**詳しい説明**

```
苔むす日本庭園に、鹿威し（ししおどし）の「カコーン！」が響く。
竹筒が石を打つその一瞬に、画面をタップ。ぴたりと合えば PERFECT。
音と景色に癒やされながら、指先のタイミングを磨くワンタップゲームです。

■ 本物の鹿威しの動き
・筧（かけい）から落ちる水が竹筒に溜まり、口側がゆっくり沈んでいく
・水がこぼれて軽くなった竹筒が、石側から一気に落ちて石を打つ
・こぼれた水は手水鉢へ。あふれた水は小川を流れ、鯉の泳ぐ池へ注ぐ

■ タップするのは「カコーン！」の瞬間
・石に向かって縮んでくる輪が、石の上の輪と重なったときが PERFECT
・判定は PERFECT・GREAT・GOOD・MISS の4段階
・連続で成功するとコンボ倍率が上がり、最大3倍に
・MISS が3回でゲームオーバー

■ PERFECT は盛大に
・金色のフラッシュ、石から立ちのぼる光の柱、桜吹雪
・カメラがぐっと寄り、鈴の音が陽音階を駆け上がる
・連続 PERFECT で花びらが増えていく

■ レベルが上がると、庭が変わる
・雨：水の流れが速くなる
・風：竹筒の動きが微妙に変わり、シダが揺れ、葉が舞う
・夜：月明かりの庭。石灯籠と茶室の障子が灯り、蛍が飛ぶ
・竹筒のサイズ：太い竹筒、細い竹筒
・2本の鹿威し：2本目が現れて、交互に鳴る
・レベル7からは、これらが組み合わさって登場

■ 歩いて回りたくなる日本庭園
・苔むす森を背景に、茶室、縁側で眠る猫、しだれ桜と黒松
・白砂に砂紋を描いた枯山水、石灯籠、飛び石、竹林ともみじ
・カメラは庭をゆっくり一周しながら、低い視点から見下ろす視点まで行き来。毎回ちがう景色で遊べる

■ 音にもこだわり
・「カコーン」の音、竹筒に水が溜まる音、雨や風の音
・大正琴の音色によるゆったりした BGM（毎回ちがう旋律）

■ その他
・「新米庭師」から「伝説の庭師」までの称号と、プレイの記録
・スコアと称号を友だちにシェア
・好きなギミックを最初から試せる練習モード
・3回目の MISS のあと、広告を見ると MISS を1つ取り消して続けられる（1ゲーム2回まで）
・オフラインでも遊べる（広告・シェアは通信が必要）
・日本語・英語対応

さあ、耳をすませて。カコーン！
```
