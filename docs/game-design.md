# ゲーム企画書：鹿威しカコーン（Japan Garden KAKOON!）

## ゲームオーバー画面
ゲームオーバー時に次の選択肢を表示します。

```
GAME OVER
1,280
YOUR SCORE

[▶ 動画を見てコンティニュー]  広告視聴後、残機を1回回復して再開
[  もう一度遊ぶ            ]  広告なしで再スタート
```

- コンティニューは1プレイにつき1回までにします。
- 動画を最後まで見なかった場合は回復しません。
- 動画広告が読み込まれていない場合、ボタンは押せない状態にします。

## インタースティシャル広告
初期ルール（`src/ads.js` の `DEFAULT_AD_RULES`）は次のとおりです。

| ルール | 実装 |
|---|---|
| 3プレイに1回程度 | `interstitialEveryNPlays: 3` |
| プレイ中には絶対に表示しない | プレイ中は `shouldShowInterstitial` が常に false |
| リザルト画面の区切りで表示 | 「もう一度遊ぶ」押下時にのみ判定 |
| アプリ起動直後には表示しない | `minSecondsSinceLaunch: 60` |
| 広告が読み込まれていなければスキップ | `isLoaded('interstitial')` が false なら表示しない |
| 連続して広告を表示しない | 前回の広告（動画を含む）から `minSecondsBetweenAds: 60` 秒あける |

広告頻度はユーザーの離脱率を見ながら調整します。

## 収益シミュレーション
以下は実績ではなく、仮定に基づく計算例です。

| 項目 | 仮定 |
|---|---|
| DAU | 1,000人 |
| 1人あたりプレイ | 8回 |
| 1人あたり広告表示 | 2回 |
| 1日広告表示数 | 2,000回 |
| 仮の広告eCPM | 200円 |

1日の収益 = 2,000 ÷ 1,000 × 200 = **400円**

月間（30日）の試算 = 400円 × 30 = **12,000円**

実際の収益は国、OS、広告形式、広告充足率、季節などで大きく変わります。
最初は広告収益の最大化よりも、継続率とプレイ回数を優先します。
