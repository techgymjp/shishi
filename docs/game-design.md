# ゲーム企画書（要点）：鹿威しカコーン / Japan Garden KAKOON!

**リアルな日本庭園を舞台に、鹿威しを絶妙なタイミングで鳴らすワンタップゲーム。**
「水が溜まる → 竹筒が傾く → タップ → カコーン！」という気持ちよさを中心に置きます。

| 項目 | 内容 |
|---|---|
| サブタイトル | 鹿威しタイミングチャレンジ |
| ジャンル | ハイパーカジュアル |
| 画面 | 縦画面・ワンタップ |
| 1プレイ | 約30〜60秒 |
| 収益化 | 広告（リワード・インタースティシャル） |

## ゲームルール
- 判定：PERFECT ±0.05秒（100点）／GREAT ±0.11秒（70点）／GOOD ±0.20秒（40点）／MISS（0点）※プレイして厳しめに調整
- 判定は竹筒のアニメーションではなく、内部の衝突予定時刻を基準にする
- タップしなくても鹿威しは自然に動いて鳴る（タップはタイミングを競う操作）
- MISSが3回でゲームオーバー。10回成功するごとに難易度が上がる。連続成功で水の流入が速くなる
- コンボ倍率：1〜4 ×1.0／5〜9 ×1.2／10〜19 ×1.5／20〜29 ×2.0／30以上 ×3.0
- 獲得点 = 基本点 × コンボ倍率

## 画面構成（タイトル → ゲーム → リザルト）
- **タイトル**：動いている鹿威し、タイトル、START、BEST SCORE、サウンドON/OFF、設定
- **ゲーム**：左上スコア、右上BEST、上部中央コンボ、中央に鹿威し、中央下「TAP!」（水位ゲージは、満タンでタップするゲームと誤解されやすいため置かない）。画面全体がタップ可能。タイミングが近づくと控えめに光る
- **判定演出**：PERFECT＝水しぶき＋画面フラッシュ＋大きな文字＋0.2秒のスロー／GREAT＝水しぶき＋文字／GOOD＝小さな水しぶき／MISS＝画面が少し暗くなる
- **リザルト**：スコア、BEST、PERFECT回数、GREAT回数、最大コンボ、コンティニュー（リワード広告）、もう一度遊ぶ、HOME

## 広告（アプリ版のみ。Web版には入れない）
### リワード広告
ゲームオーバー時に「▶ 動画を見てコンティニュー（広告視聴後、残機を1回回復して再開）」と「もう一度遊ぶ（広告なしで再スタート）」を表示します。コンティニューは1プレイにつき1回までです。

### インタースティシャル広告（初期ルール：`src/ads.js` の `DEFAULT_AD_RULES`）
- 3プレイに1回程度
- プレイ中には絶対に表示しない
- リザルト画面の区切りで表示する
- アプリ起動直後には表示しない（起動から60秒）
- 広告が読み込まれていなければスキップする
- 連続して広告を表示しない（前回の広告から60秒あける）

### 収益シミュレーション（仮定に基づく計算例）
DAU 1,000人 × 1人あたり広告2回 = 1日2,000インプレッション、eCPM 200円の場合：
2,000 ÷ 1,000 × 200 = **1日400円**、30日で **月12,000円**。
最初は広告収益の最大化よりも、継続率とプレイ回数を優先します。
