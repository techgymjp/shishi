# 鹿威しカコーン（Japan Garden KAKOON!）

日本庭園の鹿威しを、絶妙なタイミングで鳴らすワンタップゲームです。ブラウザで動く3D（three.js）で、実写由来の素材を使ったリアルな庭園を表示します。

**遊ぶ：** https://techgymjp.github.io/shishi/

## 遊び方
1. 筧（かけい）から竹筒に水が溜まっていきます。
2. 満水になると竹筒が傾いて水がこぼれます。
3. 空になった竹筒は戻って石に当たり、「カコーン！」と鳴ります。**石に当たる瞬間に画面をタップ**してください。
4. タップしなくても鹿威しは自然に動いて鳴ります。タップは、タイミングの良さを競うための操作です。

| 判定 | 衝突時刻とのずれ | 基本点 |
|---|---|---:|
| PERFECT | ±0.05秒以内 | 100 |
| GREAT | ±0.11秒以内 | 70 |
| GOOD | ±0.20秒以内 | 40 |
| MISS | それ以外・タップなし | 0 |

- 連続成功でコンボ倍率がかかります（5〜9：×1.2、10〜19：×1.5、20〜29：×2.0、30以上：×3.0）。
- 10回成功するごとにレベルが上がり、水の流入と竹筒の戻りが速くなります。
- **MISSが3回でゲームオーバー**です。
- 竹筒が傾く前のタップは無視されます。タップは1サイクルにつき1回までです。
- PCではスペースキーでもタップできます。

## 鹿威しの動き
- 水が溜まるにつれて、口側（右）が水の重みで**ゆっくり**下がります。傾ききると水がこぼれます。
- 水が抜けると口側が急に軽くなり、石側（左）が重力で**一気に**落ちて石を打ちます（カコーン！）。
- 石を打つ瞬間がタップのタイミングです。縮んでくる輪が、石の上の輪と重なった瞬間が PERFECT です。
- 衝突の0.6秒より前のタップは「まだ」と表示され、MISSにはなりません。竹筒は、溜まった水の量に応じて沈んで戻ります（水が少ないとゆっくり）。

## PERFECT の演出
金色のフラッシュ、石から立ちのぼる光の柱、地面を走る金色の衝撃波、桜吹雪、カメラの寄りと揺れ、陽音階を駆け上がる鈴の音。
連続で PERFECT を出すと「N連続」と表示され、花びらが増えます。

## 庭の水の流れ
筧 → 鹿威し → 手水鉢 → 小川 → 池（鯉と睡蓮）。手水鉢からあふれた水が小川を流れ、奥の池に注ぎます。

## 追加ギミック
| 登場 | ギミック | 効果 |
|---|---|---|
| Lv.2 | ☔ 雨 | 水の流入が速くなり、雨脚で毎回変わる。雨音・水面の波紋 |
| Lv.3 | 🍃 風 | 竹筒の沈む速さ・落ちる速さが微妙に変わる。シダが揺れ、葉が舞う |
| Lv.4 | 🌙 夜 | 月明かりの庭園。石灯籠が灯り、蛍が飛ぶ。見えにくくなる |
| Lv.5 | 🎋 竹筒のサイズ | 竹筒が太く（溜まるのが遅い）・細く（速い）なる |
| Lv.6 | ⇄ 2本の鹿威し | 2本目が現れ、交互に鳴る。近い方が判定される |
| Lv.7〜 | 組み合わせ | 2つ（Lv.20以降は3つ）のギミックがランダムに組み合わさる |

設定画面の「練習（ギミック）」で、好きなギミックを最初から有効にして遊べます。

## BGM（大正琴風）
`src/bgm.js` で、大正琴風のゆっくりした BGM をその場で合成しています（音源ファイルなし）。
- 弦の振動を再現する Karplus-Strong 法で、少しずらした2本の金属弦の音を作っています。
- 陽音階（レ・ミ・ソ・ラ・シ）で、遊ぶたびに変わるオリジナルの旋律です。長い音は大正琴らしいトレモロで伸ばします。
- 設定画面の「BGM（大正琴）」でオン・オフを切り替えられます。

## カメラ
カメラは庭を左まわり（上から見て反時計回り）に約90秒で1周します。地面すれすれの低い視点から見下ろす高い視点まで、ゆっくり行き来します。

## 起動方法（ローカル）
ES Modules を使っているため、ローカルサーバー経由で開きます。

```bash
python3 -m http.server 8000
```

ブラウザで http://localhost:8000/ を開きます。

## 構成
| ファイル | 内容 |
|---|---|
| `index.html` / `style.css` | 画面（読み込み・タイトル・ゲーム・リザルト・設定） |
| `src/main.js` | ゲーム全体の状態管理、入力、画面遷移 |
| `src/scene3d.js` | 3Dの日本庭園と鹿威し（three.js）、水流・水しぶき・波紋・光の演出 |
| `src/shishi.js` | 鹿威しの動き（水が溜まる → 傾く → 戻って衝突）と衝突予定時刻 |
| `src/rules.js` | 判定・スコア・コンボ倍率・難易度・称号・記録 |
| `src/audio.js` | 「カコーン」・水音（泡の音）・雨音・風音・判定音（Web Audio で合成） |
| `src/bgm.js` | 大正琴風の BGM（Web Audio で合成） |
| `src/ads.js` | 広告ルール（**アプリ版用**。Web版では読み込んでいません） |
| `assets/` | HDRI・3Dモデル・テクスチャ（Poly Haven / CC0、`assets/CREDITS.md`） |
| `vendor/three/` | three.js r180 |
| `tests/` | ルール・鹿威しの動き・広告ルールのテスト |
| `docs/game-design.md` | 企画書の要点 |

判定は見た目のアニメーションではなく、`ShishiOdoshi` が管理する**衝突予定時刻**を基準にしています。描画と判定を分けて、音と判定が必ず一致するようにしています。

## 3D表示について
- 背景と環境光には、苔むした森のHDRI（360°の実写画像）を使っています。地面に投影して、庭と奥の森をつないでいます。
- 庭石・シダは3Dスキャン素材です。地面・玉砂利・手水鉢には実写のテクスチャを使っています。
- 端末が重い場合は、描画解像度と影の精度を自動で下げます。
- 読み込むデータは合計約12MBです。

## 広告について
Web版には広告を入れていません。リワード広告によるコンティニューとインタースティシャル広告は、アプリ版で実装する予定です（ルールは `src/ads.js` と `docs/game-design.md`）。
