# 鹿威しカコーン（Japan Garden KAKOON!）

日本庭園の鹿威しを、絶妙なタイミングで鳴らすワンタップゲームです。ブラウザで遊べます。

**遊ぶ：** https://techgymjp.github.io/shishi/ （GitHub Pages の公開設定後に表示されます）

## 遊び方
1. 筧（かけい）から竹筒に水が溜まっていきます。
2. 満水になると竹筒が傾いて水がこぼれます。
3. 空になった竹筒は戻って石に当たり、「カコーン！」と鳴ります。**石に当たる瞬間に画面をタップ**してください。
4. タップしなくても鹿威しは自然に動いて鳴ります。タップは、タイミングの良さを競うための操作です。

| 判定 | 衝突時刻とのずれ | 基本点 |
|---|---|---:|
| PERFECT | ±0.10秒以内 | 100 |
| GREAT | ±0.20秒以内 | 70 |
| GOOD | ±0.35秒以内 | 40 |
| MISS | それ以外・タップなし | 0 |

- 連続成功でコンボ倍率がかかります（5〜9：×1.2、10〜19：×1.5、20〜29：×2.0、30以上：×3.0）。
- 10回成功するごとにレベルが上がり、水の流入と竹筒の戻りが速くなります。
- **MISSが3回でゲームオーバー**です。動画広告を見ると、1プレイに1回だけ残機を回復して続けられます。
- 竹筒が傾く前のタップは無視されます。タップは1サイクルにつき1回までです。
- PCではスペースキーでもタップできます。

## 起動方法（ローカル）
ES Modules を使っているため、ローカルサーバー経由で開きます。

```bash
python3 -m http.server 8000
```

ブラウザで http://localhost:8000/ を開きます。

## テスト
```bash
npm test
```

## 構成
| ファイル | 内容 |
|---|---|
| `index.html` / `style.css` | 画面（タイトル・ゲーム・リザルト・設定・広告） |
| `src/main.js` | ゲーム全体の状態管理、入力、画面遷移 |
| `src/shishi.js` | 鹿威しの動き（水が溜まる → 傾く → 戻って衝突）と衝突予定時刻 |
| `src/rules.js` | 判定・スコア・コンボ倍率・難易度・称号・記録 |
| `src/renderer.js` | 日本庭園と鹿威しの描画（Canvas）、水しぶき・光などの演出 |
| `src/audio.js` | 「カコーン」・水音・判定音（Web Audio で合成） |
| `src/ads.js` | 広告ルール（`AdPolicy`）、収益試算、デモ用広告 |
| `tests/` | ルール・鹿威しの動き・広告ルールのテスト |
| `docs/game-design.md` | 企画書の要点 |

判定は見た目のアニメーションではなく、`ShishiOdoshi` が管理する**衝突予定時刻**を基準にしています。描画と判定を分けて、音と判定が必ず一致するようにしています。

## 広告について
現在の広告は**デモ用のモック**（`MockAdProvider`）です。本番では AdMob（アプリ化時）や Google AdSense for Games（H5）に差し替えます。差し替えが必要なのは `isLoaded` と `show` の2つだけです。

## 公開（GitHub Pages）
`main` に push すると、`.github/workflows/pages.yml` がテストを実行してから公開します。初回だけ、次の設定が必要です。
- **Settings → Actions → General** で Actions を許可する
- **Settings → Pages → Source** を **GitHub Actions** にする
