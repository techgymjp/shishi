# 鹿威しカコーン（Japan Garden KAKOON!）

日本庭園の鹿威しを、絶妙なタイミングで鳴らすワンタップゲームです。ブラウザで動く3D（three.js）で、実写由来の素材を使ったリアルな庭園を表示します。

**遊ぶ：** https://techgymjp.github.io/shishi/

## 遊び方
1. 筧（かけい）から竹筒に水が溜まっていきます。
2. 満水になると竹筒が傾いて水がこぼれます。
3. 空になった竹筒は戻って石に当たり、「カコーン！」と鳴ります。**石に当たる瞬間に画面をタップ**してください。
4. タップしなくても鹿威しは自然に動いて鳴ります。タップは、タイミングの良さを競うための操作です。

| 判定 | 衝突時刻とのずれ | 基本点 |
|---|---|---:|
| PERFECT | ±0.05秒以内 | 100 |
| GREAT | ±0.11秒以内 | 70 |
| GOOD | ±0.20秒以内 | 40 |
| MISS | それ以外・タップなし | 0 |

- 連続成功でコンボ倍率がかかります（5〜9：×1.2、10〜19：×1.5、20〜29：×2.0、30以上：×3.0）。
- 10回成功するごとにレベルが上がり、水の流入と竹筒の戻りが速くなります。
- **MISSが3回でゲームオーバー**です。
- 竹筒が傾く前のタップは無視されます。タップは1サイクルにつき1回までです。
- PCではスペースキーでもタップできます。

## 鹿威しの動き
- 水が溜まるにつれて、口側（右）が水の重みで**ゆっくり**下がります。傾ききると水がこぼれます。
- 水が抜けると口側が急に軽くなり、石側（左）が重力で**一気に**落ちて石を打ちます（カコーン！）。
- 石を打つ瞬間がタップのタイミングです。縮んでくる輪が、石の上の輪と重なった瞬間が PERFECT です。
- 衝突の0.6秒より前のタップは「まだ」と表示され、MISSにはなりません。竹筒は、溜まった水の量に応じて沈んで戻ります（水が少ないとゆっくり）。

## PERFECT の演出
金色のフラッシュ、石から立ちのぼる光の柱、地面を走る金色の衝撃波、桜吹雪、カメラの寄りと揺れ、陽音階を駆け上がる鈴の音。
連続で PERFECT を出すと「N連続」と表示され、花びらが増えます。

## 庭の水の流れと景色
- 筧 → 鹿威し → 手水鉢 → 小川 → 池（鯉と睡蓮）。手水鉢からあふれた水が小川を流れ、奥の池に注ぎます。
- 池の向こうに草庵風の茶室があります（茅葺き屋根、土壁、障子、にじり口・貴人口、濡れ縁、礎石、沓脱石）。池のほとりから飛び石が続き、夜は障子が灯ります。プレイ中も、茶室が見える向きでは屋根まで画面に入るようカメラを合わせます。
- 茶室の縁側では茶トラの猫が歩いたり、座って見回したり、丸くなって眠ったりします（夜はよく眠ります）。
- 茶室の縁側から見て鹿威しの向こう側に枯山水があります。白砂の砂紋（直線と、石のまわりの同心円）、石組み、苔の島、縁石。
- 池と飛び石の右手には玉づくりの黒松（根元に添え石）、左手にはしだれ桜（花びらが舞う）があり、茶室の両脇で対になっています。
- 遠景に竹林ともみじがあり、風のギミックでは大きく揺れます。カメラの通り道より外側に置いているので、視界をふさぎません。
- カメラが庭の裏側に回り、茶室が鹿威しとの間に入るときは、茶室を消して鹿威しが見えるようにしています。

## 追加ギミック
| 登場 | ギミック | 効果 |
|---|---|---|
| Lv.2 | ☔ 雨 | 水の流入が速くなり、雨脚で毎回変わる。雨音・水面の波紋 |
| Lv.3 | 🍃 風 | 竹筒の沈む速さ・落ちる速さが微妙に変わる。シダが揺れ、葉が舞う |
| Lv.4 | 🌙 夜 | 月明かりの庭園。石灯籠が灯り、蛍が飛ぶ。見えにくくなる |
| Lv.5 | 🎋 竹筒のサイズ | 竹筒が太く（溜まるのが遅い）・細く（速い）なる |
| Lv.6 | ⇄ 2本の鹿威し | 2本目が現れ、交互に鳴る。近い方が判定される |
| Lv.7〜 | 組み合わせ | 2つ（Lv.20以降は3つ）のギミックがランダムに組み合わさる |

設定画面の「練習（ギミック）」で、好きなギミックを最初から有効にして遊べます。

## BGM（大正琴風）
`src/bgm.js` で、大正琴風のゆっくりした BGM をその場で合成しています（音源ファイルなし）。
- 弦の振動を再現する Karplus-Strong 法で、少しずらした2本の金属弦の音を作っています。
- 陽音階（レ・ミ・ソ・ラ・シ）で、遊ぶたびに変わるオリジナルの旋律です。長い音は大正琴らしいトレモロで伸ばします。
- 設定画面の「BGM（大正琴）」でオン・オフを切り替えられます。

## カメラ
- 庭を左まわり（上から見て反時計回り）に、一定の速さで約90秒かけて一周します。
- 高さ（ローアングル⇔ハイアングル）は約41秒、距離（近景⇔遠景）は約59秒の周期で行き来します。周期がそろわないので、一周ごとに違う景色になります。
- どの角度でも、打ち石とタイミングの輪が画面に収まる距離まで自動で引きます。茶室が見える向きでは、視線を上げて屋根も入れます。
- 茶室・松・桜がカメラと鹿威しの間に入るときは、透けて消えます。
- 開始アングル（方位・高さ・距離の周期の位置）は毎回ランダムです。

## シェアと英語対応
- リザルト画面の「シェア」から結果を共有できます（共有するURLは https://techgym.jp/column/claude-code-game-shishi/ ）。スマホでは端末の共有メニュー（LINE・X・メッセージなど）が開きます。共有メニューがない環境では X・LINE・Facebook・コピーを表示します。
- リンクをシェアしたときは `assets/og.jpg` の画像が表示されます（OGP）。
- 端末の言語が日本語以外なら英語で表示します。設定画面の「言語 / Language」で切り替えられます（`src/i18n.js`）。

## 3D表示について
- 背景と環境光には、苔むした森のHDRI（360°の実写画像）を使っています。地面に投影して、庭と奥の森をつないでいます。
- 庭石・シダは3Dスキャン素材です。地面・玉砂利・手水鉢には実写のテクスチャを使っています。
- 端末が重い場合は、描画解像度と影の精度を自動で下げます。
- プレイ中に画面が止まらないよう、次の工夫をしています。
  - 描画プログラム（シェーダー）は読み込み時にすべて作っておく
  - ライトの数を変えない（増減すると全素材の作り直しになるため）
  - 水流の形は使い回す
  - BGMの音は前もって作っておく
- 読み込むデータは合計約12MBです。

## Android アプリ

[Capacitor](https://capacitorjs.com/) でゲームのファイルをアプリに同梱し、Android アプリにしています（オフラインで遊べます）。
構成は techgymjp/jet-fighter の `docs/ANDROID_PORTING.md`、techgymjp/corner-kick と同じです。

- **動作確認用 APK**（デバッグ署名・テスト広告。Google Play 版ではありません）
  - リリース画面: https://github.com/techgymjp/shishi/releases/tag/android-latest
  - APK 直接: https://github.com/techgymjp/shishi/releases/latest/download/shishi.apk
  - QR コード（リリース画面）: [`docs/apk-qr.png`](docs/apk-qr.png)

  ![APK のリリース画面の QR コード](docs/apk-qr.png)

- パッケージ名: `jp.techgym.shishi`
- アプリ名: 鹿威しカコーン（英語の端末では KAKOON!）
- 縦画面固定・全画面・プレイ中は画面を消さない
- トップ画面は「▶ プレイ」「あそびかた」だけ。遊び方は「あそびかた」画面にまとめています
- 戻るボタン: プレイ中は一時停止（一時停止中なら再開）、あそびかたではタイトルへ、タイトル・結果画面ではアプリを終了
- 画面左下の「Ⅱ」でも一時停止できます。別アプリに切り替えると、自動で一時停止して音を止めます
- シェアは Android の共有メニュー
- 広告（AdMob）
  - バナー: タイトル・あそびかた・一時停止・結果画面の下中央（プレイ中は出さない）
  - 全画面広告（インタースティシャル）: 「プレイ」（タイトル・あそびかたから）、「タイトルへ」（あそびかた・一時停止・結果画面から）、一時停止からの「再開」、結果画面の「もう一度遊ぶ」のたびに毎回
  - リワード広告（チート）: 3 回目の MISS でゲームオーバーになったら「広告を見て続ける」（1 ゲーム 2 回まで）。
    MISS を見届けられるよう 2.2 秒後に出し、6 秒で自動的に結果画面へ。最後まで見るとその MISS を取り消し（MISS 2 回・コンボも戻る）、続きから遊べます。
    使ったことは結果画面とシェア文に「コンティニュー N 回」と出ます
  - EU など同意が必要な地域では、タイトル画面に「広告の設定」
  - 広告ユニット ID は `src/admob.js` の `UNITS.android.production`、AdMob のアプリ ID は `android/app/src/main/res/values/strings.xml` の `admob_app_id`。
    本番の ID が届くまではテスト用の ID です（本番ビルドでは、ID が空の種類の広告は出しません）
- タイトル画面の下に、バージョン（アプリ版のみ）とプライバシーポリシーへのリンク
- GitHub Actions（`.github/workflows/android.yml`）で、push のたびにビルドします
  - 既定ブランチのビルドは、Release `android-latest` の `shishi.apk` を差し替えます
  - GitHub Secrets（`ANDROID_KEYSTORE_BASE64`・`ANDROID_KEYSTORE_PASSWORD`・`ANDROID_KEY_ALIAS`・`ANDROID_KEY_PASSWORD`）を登録すると、本番広告の署名付き AAB（Google Play 用）も作り、Artifact `shishi-release-aab` に上げます

ストア掲載用の画像と紹介文（日英）は [`docs/store/`](docs/store/) にあります（Google Play 用の下書きは `docs/store/listing.md`）。

手元で試すとき: `npm install` → `npm run android:sync` → `npm run android:open`（Android Studio が必要）。
アイコンと起動画面の元画像は `resources/` にあります。
